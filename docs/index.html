Noxy
Statically Typed Programming Language

A powerful statically typed language with a high-performance stack-based Virtual Machine written in Go, created by Estêvão Fonseca. Supports primitives, structs, dynamic arrays, maps, and much more.

Since 0.4.0, arrays, maps and structs behave as independent values at any depth — ref is the only sharing mechanism, and copy-on-write keeps the copies lazy.

Language Features

Value Semantics 0.4.0

Arrays, maps and structs are independent values at any depth. Nothing is copied on the binding: copy-on-write clones lazily, one level at a time, on the first write to a shared value.

Static Type System

Full support for int, float, string, bool, and array types with compile-time type checking.

Stack-Based VM

Stack-based Virtual Machine written in Go for high performance and portability.

Data Structures

Native support for structs, arrays, self-referencing, and complex data structures.

Advanced Algorithms

Implementation of binary search, linked lists, binary trees, and sorting algorithms.

Explicit Sharing with ref

Recursive data structures and in-place mutation through ref — the single, explicit mechanism for sharing storage across calls, channels and routines.

Type Conversions

Universal to_str function and numeric conversions for flexible data manipulation.

Concurrency

Go-style concurrency with spawn and channels for parallel execution on multiple cores. Since 0.4.0, data sent by argument or channel is race-free by construction.

First-Class Functions

Support for anonymous functions, closures with captured variables, and passing functions as arguments.

What's New in v0.4.0

Composite values became independent deep copies at every binding without ref — assignment, calls, container reads and writes, channels, spawn/spawn_task and defer capture. The runtime implements the contract with copy-on-write: nothing is copied on the binding, and the clone happens lazily on the first mutation of a shared value. These are breaking changes; the migration for each one is below.

Assignment no longer aliases

let a: int[] = [1, 2, 3]
let b: int[] = a
b[0] = 99

print(a[0]) // 0.3.x: 99  |  0.4.0: 1

// Migration: use ref to keep sharing
let alias: ref int[] = ref a
alias[0] = 99
print(a[0]) // 99

Reading from a container copies

let people: Person[] = [Person("Ana", 30)]

let p: Person = people[0]
p.age = 31
print(people[0].age) // 0.4.0: 30

// Migration: mutate through the path...
people[0].age = 31
// ...or borrow the slot with ref
let slot: ref Person = ref people[0]
slot.age = 32

Nested mutation no longer leaks

// Without ref the parameter is independent
// at ANY depth (the old shallow copy only
// protected the outer container).
func touch(box: Box)
    box.values[0] = 99   // caller unaffected
end

// Migration: declare the parameter as ref
func bump(box: ref Box)
    box.values[0] = 99   // caller sees it
end

== on composites is structural

print([1, 2] == [1, 2])
// 0.3.x: false (pointer identity)
// 0.4.0: true  (compared by content)

// refs still compare by slot identity
// and are not dereferenced.

// Migration for identity checks:
// compare refs, or compare a key of
// your own.

spawn lost its identity exception

// Arguments now follow the same value
// semantics as a normal call, and
// chan_send delivers an independent value.
spawn(worker, data)   // worker gets a copy

// Migration for shared mutable state:
// a coordinated global, or channels.

append stores an independent value

let item: int[] = [1]
let dest: int[][] = []
append(dest, item)
item[0] = 99

print(dest[0][0]) // 0.4.0: 1

// append/pop/delete clone a shared target
// before mutating it (CoW through the slot).

Full list of breaking changes and migrations in the CHANGELOG. The contract is specified in the language spec §2.2, and the sharing rules in reference semantics.

Concurrency (Producer-Consumer)

Using channels to communicate between concurrent routines. Since v0.4.0, arguments to spawn and values sent over a channel are independent values — data handed to another routine is race-free by construction.

use time

func worker(id: int, c: chan string)
    time.sleep(100)
    chan_send(c, "Message from " + to_str(id))
end

func main()
    let c: chan string = make_chan(0)
    spawn(worker, 1, c)
    spawn(worker, 2, c)

    // Receive 2 messages
    print(chan_recv(c))
    print(chan_recv(c))
end

main()

Value Semantics (v0.4.0)

Arrays, maps and structs are independent values at any depth. ref is the only way to share storage, and copy-on-write means the copy costs nothing until someone writes.

struct Counter
    hits: int[]
end

// No 'ref': the callee gets an independent value at any depth.
func touch(c: Counter)
    c.hits[0] = 999
end

// With 'ref': the callee shares the caller's storage.
func bump(c: ref Counter)
    c.hits[0] = c.hits[0] + 1
end

let counter: Counter = Counter([1, 2, 3])

touch(counter)
print(counter.hits[0])   // 1 - the copy was mutated, not the original

bump(counter)
print(counter.hits[0])   // 2 - ref shares the original

let backup: Counter = counter
bump(counter)
print(backup.hits[0])    // 2 - assignment already copied

print([1, 2] == [1, 2])  // true - composites compare by content

Binary Tree

Implementation of a binary tree with pre-order traversal. The nodes are plain values; the traversal borrows each node with ref so no subtree is copied.

struct Node
    data: int,
    left: Node,
    right: Node
end

// Create binary tree
let root: Node = Node(1, null, null)
root.left = Node(2, null, null)
root.right = Node(3, null, null)
root.left.left = Node(4, null, null)
root.left.right = Node(5, null, null)

func pre_order(node: ref Node)
    if node != null then
        print(to_str(node.data))
        pre_order(node.left)
        pre_order(node.right)
    end
end

pre_order(root)   // 1 2 4 5 3

Linked List

Implementation of a linked list with insertion and printing operations. Every function that must reach the caller's list takes it by ref; ref current.next rebinds the cursor to the next slot without copying the tail.

struct Node
    value: int,
    next: Node
end

// 'ref' shares the caller's node; without it the callee gets a copy.
func push_back(node: ref Node, value: int)
    if node.next == null then
        node.next = Node(value, null)
    else
        push_back(node.next, value)
    end
end

func print_list(node: ref Node)
    let current: ref Node = node
    while current != null do
        print(to_str(current.value))
        current = ref current.next
    end
end

let list: Node = Node(10, null)
push_back(list, 20)
push_back(list, 30)
print_list(list)   // 10 20 30

HashMap

Implementation of a hashmap with string keys using a polynomial hash function. Walking a bucket chain through ref keeps the traversal free of copies — reading a slot into a plain variable would give you a copy to mutate.

struct Entry
    key: string,
    value: string,
    next: Entry
end

let buckets: Entry[16]

func hash(key: string, size: int) -> int
    let hash_value: int = 0
    let i: int = 0
    while i < length(key) do
        hash_value = (hash_value * 31 + ord(key[i])) % size
        i = i + 1
    end
    return hash_value
end

func put(key: string, value: string)
    let index: int = hash(key, 16)
    if buckets[index] == null then
        buckets[index] = Entry(key, value, null)
        return
    end
    // Walk the chain through a ref: no copy, we mutate in place.
    let node: ref Entry = ref buckets[index]
    while node.next != null do
        node = ref node.next
    end
    node.next = Entry(key, value, null)
end

func get(key: string) -> string
    let node: ref Entry = ref buckets[hash(key, 16)]
    while node != null do
        if node.key == key then
            return node.value
        end
        node = ref node.next
    end
    return ""
end

put("owl", "purple")
put("lang", "noxy")
print(get("owl"))    // purple
print(get("lang"))   // noxy

Safe Division

Result pattern for safe error handling in operations that may fail.

struct Result
    is_ok: bool,
    value: int,
    error: string
end

func Ok(value: int) -> Result
    return Result(true, value, "")
end

func Err(error_name: string) -> Result
    return Result(false, 0, error_name)
end

func safe_divide(a: int, b: int) -> Result
    if b == 0 then
        return Err("DIVISION_BY_ZERO")
    end
    return Ok(a / b)
end

let result: Result = safe_divide(10, 0)
if result.is_ok then
    print("Result: " + to_str(result.value))
else
    print("Error: " + result.error)
end

Closures

Functions can capture variables from their outer scope, allowing for state encapsulation.

func makeAccount(initialBalance: int) -> func
    let balance: int = initialBalance
    
    // Return a function that captures 'balance'
    return func(amount: int) -> int
        balance = balance + amount
        return balance
    end
end

let account: func = makeAccount(100)
print("Initial: 100")
print("Deposit 50: " + to_str(account(50)))   // 150
print("Withdraw 30: " + to_str(account(-30))) // 120

HTTP Server

Built-in support for creating concurrent HTTP servers.

use http_server

func handler(req: HttpRequest) -> HttpResponse
    if req.path == "/" then
        return http_server.response_text("Hello from Noxy!")
    elif req.path == "/json" then
        return http_server.response_json("{\"status\": \"ok\"}")
    end
    return http_server.response_404()
end

// Create and start server
let server: HttpServer = http_server.new_server("127.0.0.1", 8080)
print("Server running on http://127.0.0.1:8080")

// 'ref server' is required: the module boundary erases the exact
// signature, so the compiler cannot borrow the variable for you.
http_server.serve(ref server, handler)
