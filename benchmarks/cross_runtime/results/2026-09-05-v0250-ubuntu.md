## Leitura

- Primeira medicao do cross-runtime em Linux. As razoes noxy/python sao
  piores que as publicadas no Windows (`fib` 1,16x -> 1,80x, `loop_arith`
  1,06x -> 1,28x, `string_ops` 2,17x -> 3,07x). O que mudou de lado foi o
  CPython: o build gcc + PGO/LTO do pacote Debian/Ubuntu e consistentemente
  mais rapido que o build MSVC do Windows, enquanto o Go rende parecido nas
  duas plataformas. Os tres binarios noxy disponiveis (build do HEAD, `./noxy`
  do repo, `~/go/bin/noxy` via `go install`) deram o mesmo `fib`, entao nao e
  regressao de build.
- Piso de processo: noxy 3 ms, python 10 ms — o Noxy sobe 3x mais rapido.
- Maquina diferente da dos resultados anteriores: os ms absolutos nao se
  comparam com as rodadas do Windows, so as razoes dentro desta janela.
